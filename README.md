# 🪵 Mueblería Hermanos Jota — E-Commerce

![Estado](https://img.shields.io/badge/Estado-En%20Curso-yellow?style=for-the-badge)
![Stack](https://img.shields.io/badge/Stack-MERN-blue?style=for-the-badge)

Plataforma de e-commerce en desarrollo para **Hermanos Jota**, firma argentina de mobiliario artesanal en maderas nativas y cueros. El proyecto abarca desde el catálogo interactivo y la experiencia de compra del usuario hasta un panel de administración para la gestión de productos y pedidos.

Este desarrollo se realiza como **Proyecto Final** para el **ITBA** (Instituto Tecnológico de Buenos Aires).
